# Learning Management System (LMS)

A full-stack Learning Management System built with Next.js and Node.js that enables user authentication, course management and student progress tracking.

The platform allows instructors to create and manage courses while students can enroll, follow course content and track their learning progress.

## Tech Stack

Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

Backend
- Node.js
- Express
- REST API
- JWT Authentication

Database
- MongoDB
- Mongoose

## Features

- User registration and login with JWT authentication
- Role-based access (Student / Instructor)
- Course creation and management
- Student enrollment
- Progress tracking
- Responsive UI

## Architecture

Client (Next.js / React)
        ↓
REST API (Node.js / Express)
        ↓
MongoDB Database

## Installation

Clone the repository

npm install

Run the development server

npm run dev
